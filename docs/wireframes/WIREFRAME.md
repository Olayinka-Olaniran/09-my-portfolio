## Responsive Breakpoints

### Mobile (375px – 767px)
- Single column layout for projects
- Hamburger menu
- Skill graph simplified or vertical
- Form fields stack vertically
- Reduced padding/margins

### Tablet (768px – 1023px)
- 2 columns for projects grid
- Horizontal nav visible (no hamburger)
- Skill graph readable
- Form at comfortable width

### Desktop (1024px+)
- 3 columns for projects grid
- Full horizontal nav
- Skill graph full width
- Form centered, max-width 600px

## Navigation Flow (Smooth Scroll)

```
User clicks nav link or command palette result
                    ↓
            Smooth scroll to section
                    ↓
        Section becomes visible in viewport
                    ↓
        Nav link highlights as "active"
```

## Component Details

### Hamburger Menu Interaction
```
Closed state: ☰ (three horizontal lines)
Click → Menu slides down from top
       → Hamburger rotates to ✕ (X)
Click → Menu slides up
       → Hamburger rotates back to ☰

Auto-close when user:
- Clicks a nav link
- Presses Escape
- Clicks outside menu
```

### Project Card Toggle Interaction
```
Initial: Shows default view (image, title, badges, buttons, "Details")
Click [Details] → Card reveals engineering notes (fade transition)
Click [Back] → Card returns to default view (fade transition)
```

### Copy-to-Clipboard Interaction
```
Icon state: 📋 (clipboard)
Hover → Tooltip: "Copy email address"
Click → Email copied to clipboard
      → Icon changes: ✓ (checkmark, green)
      → 2-3 seconds later
      → Icon reverts: 📋
```

### Form Validation Interaction
```
User fills form
         ↓
On blur or submit, validate each field:
  - Name: required, non-empty
  - Email: required, valid email format
  - Message: required, min 10 chars
         ↓
If error: Show red error text below field
If valid: Submit to Netlify
         ↓
Success: Show green "Message sent!" (auto-dismiss 3s)
Error: Show red "Failed. Try again."
```

### Skill Graph Interaction
```
Hover a skill node
  → Skill label brightens
  → Connected project nodes brighten
  → Non-connected projects fade

Click a project node
  → Page smoothly scrolls to that project card
  → Card becomes visible in center of screen
```

## Loading States

```
Page loads → Fade in hero
          → Fade in nav
          → Projects render with slight stagger
          → Skill graph renders last

Form submit → Button shows "Sending..."
            → Disable button
            → On success: Green message, form resets
            → On error: Red message, button re-enable
```
